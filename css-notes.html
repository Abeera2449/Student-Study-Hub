CSS Notes

Core concepts every beginner should understand.

1. What is CSS?

CSS stands for Cascading Style Sheets. It controls colors, spacing, typography, layout and responsive behavior of HTML elements. 

<link rel="stylesheet" href="style.css">

Place this link inside the HTML head to connect an external stylesheet.

2. CSS Syntax

p {
  color: #222;
  font-size: 16px;
}

p is the selector, color and font-size are properties, and the values define the styles.

3. Common Selectors

p { }          /* element selector */
.note { }      /* class selector */
#title { }     /* id selector */
nav a { }      /* descendant selector */
button:hover { } /* pseudo-class */
Tip: Prefer reusable classes for styling. IDs are useful for unique page targets and anchors.

4. CSS Box Model

Every element can be thought of as a rectangular box with four layers:

ContentPaddingBorderMargin 
* {
  box-sizing: border-box;
}

border-box makes width calculations easier because padding and border are included inside the declared width.

5. Display

  • block: starts on a new line and usually fills available width.
  • inline: stays in the same line and uses only needed width.
  • inline-block: inline placement with width/height support.
  • none: removes the element from layout.

6. Flexbox

Flexbox is useful for one-dimensional layouts: row or column.

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

justify-content controls the main axis. align-items controls the cross axis.

7. CSS Grid

Grid is useful for two-dimensional layouts with rows and columns.

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

8. Positioning

  • static: default positioning.
  • relative: keeps normal space and can be offset.
  • absolute: positioned relative to a positioned ancestor.
  • fixed: stays relative to the viewport.
  • sticky: behaves normally until a scroll threshold is reached.

9. Responsive Design

Responsive pages adapt to different screen sizes.

@media (max-width: 768px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
Remember: Avoid fixed page widths. Use flexible units such as %, rem, fr and max-width.
