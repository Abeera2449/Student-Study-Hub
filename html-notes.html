HTML Notes

Beginner-friendly revision notes with examples.

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to define the structure and content of a web page. HTML is a markup language, not a programming language.

Remember: HTML = structure, CSS = appearance.

2. Basic HTML Page Structure

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Page</title>
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>
  • <!DOCTYPE html> tells the browser to use modern HTML.
  • <head> contains metadata, title and links to stylesheets.
  • <body> contains visible page content.

3. Headings and Text

HTML provides six heading levels: h1 to h6.

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<p>This is a paragraph.</p>
<strong>Important text</strong>
<em>Emphasized text</em>
Tip: Use one clear h1 for the main page topic, then use lower heading levels in order.

4. Links and Images

<a href="https://example.com">Visit Website</a>

<img src="student.jpg" alt="Student studying at a desk">

The href attribute gives a link destination. The src attribute gives an image path. The alt attribute describes an image for accessibility and also appears if the image fails to load.

5. Lists

Unordered List

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Ordered List

<ol>
  <li>Read topic</li>
  <li>Practice</li>
</ol>

6. Tables

<table>
  <tr>
    <th>Subject</th>
    <th>Marks</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>85</td>
  </tr>
</table>

th is used for header cells and td for normal data cells.

7. Forms

<form>
  <label for="name">Name</label>
  <input id="name" type="text" name="name">

  <label for="email">Email</label>
  <input id="email" type="email" name="email">

  <button type="submit">Submit</button>
</form>

Forms collect user input. Common input types include text, email, password, radio, checkbox and date.

Important: A form can be displayed using only HTML/CSS, but saving submitted data needs a backend or external form service.

8. Semantic HTML

Semantic elements describe the purpose of content. They make pages easier to understand, maintain and navigate.

headernavmainsection articleasidefooter

9. Best Practices

  • Use semantic elements where appropriate.
  • Add meaningful alt text to informative images.
  • Use labels with form controls.
  • Keep heading levels logical.
  • Indent code consistently.
  • Use lowercase file names without spaces for simpler URLs.
