# Student Study Hub

Static GitHub Pages website built using HTML and CSS only.

## Files
- index.html — home page
- html-notes.html — HTML study notes
- css-notes.html — CSS study notes
- quizzes.html — static HTML/CSS quiz
- style.css — shared styling

## Run locally
Open index.html in a browser.

## Publish with GitHub Pages
Upload these files to a GitHub repository, then enable GitHub Pages from the repository settings.

## Future expansion
You can later add JavaScript for quiz scoring, Python/Java notes as new HTML pages, and a backend/database for note submissions.
