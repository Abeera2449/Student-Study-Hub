HTML & CSS Quiz

This version uses only HTML and CSS. Try each question before opening the answer.

1. Which HTML element contains the main visible page content?

  1. <head>
  2. <body>
  3. <meta>
  4. <title>
Show answer

B — <body>. Visible page content is placed inside the body element.

2. Which attribute describes an image for accessibility?

  1. href
  2. src
  3. alt
  4. title
Show answer

C — alt. It provides a text alternative for an image.

3. Which HTML element creates a hyperlink?

  1. <a>
  2. <link>
  3. <p>
  4. <nav>
Show answer

A — <a>. The anchor element creates hyperlinks.

4. Which selector targets elements with class="note"?

  1. #note
  2. .note
  3. note
  4. *note
Show answer

B — .note. CSS class selectors begin with a period.

5. Which CSS property changes text color?

  1. font-color
  2. text-color
  3. color
  4. foreground
Show answer

C — color. The color property sets the foreground text color.

6. What does padding control?

  1. Space outside the border
  2. Space inside the border
  3. Text alignment
  4. Element visibility
Show answer

B — Space inside the border. Padding sits between content and border.

7. Which declaration turns a container into a flex container?

  1. position: flex;
  2. layout: flex;
  3. display: flex;
  4. flex: display;
Show answer

C — display: flex;. This activates the flex formatting context.

8. Which CSS feature is commonly used for responsive breakpoints?

  1. Media queries
  2. HTML comments
  3. Table rows
  4. Form labels
Show answer

A — Media queries. They apply CSS under specified conditions such as viewport width.

9. Which semantic element is intended for page navigation links?

  1. <aside>
  2. <nav>
  3. <main>
  4. <article>
Show answer

B — <nav>. It represents a section containing navigation links.

10. Which CSS layout system handles rows and columns particularly well?

  1. Grid
  2. Float only
  3. Text decoration
  4. Outline
Show answer

A — Grid. CSS Grid is designed for two-dimensional layout.
